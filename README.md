# داشبورد تحلیل عملکرد اینستاگرام سَرینو (sarino.shop_)

داشبورد تعاملی تحلیل داده و استراتژی محتوا برای آنلاین شاپ سَرینو.

## 🔗 لینک مشاهده آنلاین (GitHub Pages):
https://m4tinbeigi-official.github.io/sarino-analytics/

## 📊 ویژگی‌ها:
- تحلیل داده‌محور تمامی ۱۱۹ پست منتشرشده در پیج.
- استراتژی تولید محتوا: مشخص‌کردن قالب‌های برنده (ریلز) و تله‌های محتوایی (اسلایدی خشک).
- استراتژی زمان‌بندی: روزها و ساعات طلایی انتشار به همراه تقویم هفتگی.
- جدول و کارت‌های تعاملی با قابلیت فیلتر بر اساس نوع پست، جستجو در کپشن، و مرتب‌سازی بر اساس لایک، کامنت و ویو.
- نمودارهای مقایسه‌ای ویژوال عملکرد فرمت‌ها و روند ماهانه فعالیت پیج.
